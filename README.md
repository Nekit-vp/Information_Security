# Classical Cryptography Exercises

Small Java programs that demonstrate the Caesar cipher, simple substitution, frequency analysis and exhaustive search on toy alphabets.

## Explore the code

Open [`src/Work1`](src/Work1) in a Java IDE. Start with [`CodeOfCaesar.java`](src/Work1/CodeOfCaesar.java) and compare its transformations with the frequency analysis and substitution examples.

These exercises illustrate classical techniques and why they offer little protection for real data. Use established modern cryptographic libraries in applications.
